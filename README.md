# Veyra — Corporate Landing Page

A clean, fully responsive, and accessible landing page built with pure HTML and CSS.  
No frameworks, no bloat — just solid, maintainable code that works everywhere.

Designed to showcase modern front‑end standards: semantic markup, CSS Grid, Flexbox, custom properties, and WCAG‑friendly accessibility.  
Ready for any CMS or backend integration.

---

## 🛠️ Tech Stack

- **HTML5** – Semantic markup  
- **CSS3** – CSS Grid, Flexbox, CSS Variables  
- **Responsive design** – desktop‑first approach  
- **Semantic HTML** – proper structure and tags  
- **Accessibility** – ARIA, keyboard navigation, `focus-visible`  
- **Google Fonts & Fontshare** – modern typography

---

## ✨ Key Highlights

- ✅ **W3C Valid HTML & CSS** – zero errors, zero warnings. Code you can trust.  
- 📱 **Fully responsive** – looks great on every screen, from mobile to 4K.  
- ♿ **Accessible by default** – meets WCAG 2.1 AA standards (keyboard‑friendly, alt texts, ARIA labels).  
- 🍔 **CSS‑only mobile menu** – lightweight, works without JavaScript (but easily upgradeable).  
- 🧼 **Clean, maintainable CSS** – BEM‑inspired naming, reusable variables, logically organized.  
- 📄 **Complete content sections** – Hero, Benefits, AI agent, Insights, Workflow, Testimonials, Blog, FAQ, Footer – all ready for real‑world use.
